# Contributing

Thanks for your interest in improving Home Player.

## Development

1. Fork and clone the repository.
2. Open the project in Android Studio.
3. Build with `./gradlew :app:assembleDebug`.
4. Keep changes focused and include a short description of the behavior being changed.

## Pull Requests

- Do not commit local signing files, generated APKs, IDE metadata, or device logs.
- Keep user-facing text clear and avoid exposing backend URLs, tokens, or media paths in logs.
- Run a debug build before opening a pull request.

## Release Artifacts

APK files should be uploaded to the release page as assets. They should not be committed to the source repository.
