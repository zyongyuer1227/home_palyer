# Changelog

## v1.0.0 - 2026-08-23

Initial public release.

- Added live TV browsing, search, source filters, favorites, and custom groups.
- Added NAS video browsing, quality selection, episode list, and next-episode playback.
- Added Media3 playback with direct stream, proxy, relay, TS/fMP4 fallback, and reconnect handling.
- Added portrait and landscape player layouts with status-bar safe controls.
- Added multiple server profiles and connection health checks.
- Added release signing support through local-only Gradle properties.
- Hardened release builds by disabling request logging in release APKs and Android cloud backup.
